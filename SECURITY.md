# Security

Kyuwing holds real members' names, contacts and payments, so security and privacy problems matter.

**Please don't report them in a public issue.** Use GitHub's private reporting instead: the repository's **Security** tab → **Report a vulnerability** (https://github.com/jeremiahdanielregalario/kyuwing/security/advisories/new). Only the maintainer sees the report.

Include what you found, how to reproduce it, and what data it could expose. Please don't access, copy or change real data to prove a problem; a description or a reproduction on your own local copy with seed data is enough.

Things that count: anything that lets someone without the PIN change the board or fees, see contacts, notes or full names that the public pages shouldn't show, or read another game day's private data.
